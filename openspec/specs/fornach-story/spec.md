# Fornach-story Specification

> Generated by openlore v1.2.0 on 2026-10-07 14:42

## Purpose

Coordinates interactive narrative progression using Ink, manages story state and unlocked memories,
routes player choices, and bridges narrative triggers to combat encounters.

## Requirements

> `src/Fornach.Story/StoryRunner.fs`

### Requirement: ContinueToNextEvent

The system SHALL advances the narrative engine until reaching a choice point, a combat trigger, or story completion, returning the accumulated story events.

#### Scenario: ProgressDialogueText
- **GIVEN** The story can continue and no combat is pending
- **WHEN** ContinueToNextEvent is called
- **THEN** Pours story text into TextProduced events until next choice or interrupt

#### Scenario: TriggerCombatEncounter
- **GIVEN** An external start_combat function was triggered during story execution
- **WHEN** ContinueToNextEvent finishes processing text events
- **THEN** Instantiates the enemy combatant and yields a CombatInitiated event

### Requirement: ResolveCombat

The system SHALL applies the outcome of a combat encounter to the narrative engine, resuming at post-combat knots or triggering game over flow.

#### Scenario: PlayerVictory
- **GIVEN** A combat encounter ends with PlayerVictorious
- **WHEN** ResolveCombat is called with an optional target knot
- **THEN** Routes the story path to the specified knot or defaults to post_combat

#### Scenario: PlayerDefeat
- **GIVEN** A combat encounter ends with PlayerDefeated
- **WHEN** ResolveCombat is called
- **THEN** Sets IsGameOver to true, executes the death animation callback, and routes to game_over_respawn

### Requirement: ChooseChoice

The system SHALL selects an active narrative branch by its zero-based choice index.

#### Scenario: ValidChoiceSelection
<!-- openlore-test: tags=smoke (auto) -->
- **GIVEN** An index within the current available choices range
- **WHEN** ChooseChoice is called
- **THEN** Directs the Ink engine to navigate the selected choice branch

#### Scenario: OutOfRangeChoiceSelection
- **GIVEN** An index outside the range of available choices
- **WHEN** ChooseChoice is called
- **THEN** Throws ArgumentException indicating index is out of range

### Requirement: UpdatePlayer

The system SHALL updates the player combatant instance within the narrative state.

#### Scenario: UpdatePlayerCombatant
- **GIVEN** A modified Combatant instance representing class change or rewards
- **WHEN** UpdatePlayer is called
- **THEN** Replaces the Player in NarrativeState with the updated combatant

### Requirement: LoadPrologueJson

The system SHALL loads the prologue ink story json definition from embedded assembly resources or candidate filesystem paths.

#### Scenario: LoadFromEmbeddedResource
- **GIVEN** The prologue JSON exists as an embedded assembly manifest resource
- **WHEN** LoadPrologueJson is called
- **THEN** Reads and returns the JSON content string from the resource stream

#### Scenario: LoadFromFilePathFallback
- **GIVEN** No embedded resource is found but prologue.ink.json exists at a relative path
- **WHEN** LoadPrologueJson is called
- **THEN** Reads and returns the text from disk
