# Fornach-spatial Specification

> Generated by openlore v1.2.0 on 2026-10-07 14:42

## Purpose

Calculates field of view visibility using recursive shadowcasting within a directional vision cone.

## Requirements

> `src/Fornach.Spatial/Fov.fs`

### Requirement: ComputeFieldOfView

The system SHALL compute all visible grid points within a vision cone, taking into account obstacle occlusion and cone boundaries.

#### Scenario: UnobstructedVisibilityInCone
- **GIVEN** A vision cone with transparent grid tiles within its radius and aperture
- **WHEN** compute is called
- **THEN** All tiles falling within the cone radius and aperture are returned as visible

#### Scenario: OccludedTilesBehindOpaqueObstacle
- **GIVEN** An opaque obstacle blocking line of sight along an octant scan row
- **WHEN** compute is called
- **THEN** The origin tile is marked visible and tiles in the shadow behind the opaque obstacle are excluded

> `src/Fornach.Spatial/Fov.fs`

### Requirement: TraceLine

The system SHALL generate the complete ordered list of grid points connecting start to target coordinates inclusive.

#### Scenario: StraightLineBetweenPoints
- **GIVEN** A distinct start Point and target Point on the grid
- **WHEN** bresenham is called
- **THEN** Returns an ordered list of points starting at start and terminating at target

#### Scenario: IdenticalStartAndTargetPoint
- **GIVEN** A start Point that is equal to the target Point
- **WHEN** bresenham is called
- **THEN** Returns a single-element list containing only that point

> `src/Fornach.Spatial/Fov.fs`

### Requirement: CheckLineOfSight

The system SHALL determine whether all intermediate grid points between start and target are transparent, allowing the target itself to be opaque.

#### Scenario: DirectUnobstructedView
- **GIVEN** A start Point and a target Point with all intermediate tiles marked transparent
- **WHEN** check is called
- **THEN** Returns true indicating an unobstructed line of sight

#### Scenario: BlockedViewByIntermediateObstacle
- **GIVEN** A start Point and a target Point with at least one intermediate tile marked opaque
- **WHEN** check is called
- **THEN** Returns false indicating line of sight is occluded

#### Scenario: OpaqueDestinationTile
- **GIVEN** A start Point and an opaque target Point with all intermediate tiles transparent
- **WHEN** check is called
- **THEN** Returns true because inspecting the surface of an opaque target is permitted

> `src/Fornach.Spatial/Fov.fs`

### Requirement: FindShortestPath

The system SHALL compute the shortest 8-directional path from start to goal points across passable tiles using chebyshev distance heuristics.

#### Scenario: NavigablePathFound
- **GIVEN** A start Point, a passable goal Point, and an unobstructed walkable path between them
- **WHEN** aStar is called
- **THEN** Returns Some containing the ordered list of points from start to goal

#### Scenario: GoalIsImpassable
- **GIVEN** A goal Point where isPassable evaluates to false
- **WHEN** aStar is called
- **THEN** Returns None immediately without searching

#### Scenario: UnreachableGoal
- **GIVEN** A passable goal Point that is entirely surrounded by impassable tiles
- **WHEN** aStar is called
- **THEN** Returns None when open set is exhausted without reaching the goal

#### Scenario: StartEqualsGoal
- **GIVEN** A start Point equal to the goal Point
- **WHEN** aStar is called
- **THEN** Returns Some containing a list with only the start point

### Requirement: CardinalNeighbors

The system SHALL compute and return the four orthogonal cardinal neighbors (north, east, south, west) of a given point.

#### Scenario: RetrieveFourCardinalAdjacentPoints
- **GIVEN** A reference Point
- **WHEN** cardinalNeighbors is called
- **THEN** A list containing the adjacent North, East, South, and West points is returned

### Requirement: AllNeighbors

The system SHALL compute and return all eight surrounding cardinal and diagonal neighbors of a given point.

#### Scenario: RetrieveAllEightAdjacentPoints
- **GIVEN** A reference Point
- **WHEN** allNeighbors is called
- **THEN** A list containing all eight orthogonal and diagonal neighboring points is returned

### Requirement: NormalizeDegrees

The system SHALL normalize any angular degree value into the canonical [0.0, 360.0] degree range.

#### Scenario: NormalizeAngleWithinRange
- **GIVEN** An angle in degrees that may be negative or exceed 360.0
- **WHEN** normalizeDegrees is called
- **THEN** The angle is wrapped into the range [0.0, 360.0]

### Requirement: AngleDifference

The system SHALL calculate the minimal angular separation between two angles in degrees within the range [0.0, 180.0].

#### Scenario: CalculateSmallestSeparationBetweenBearings
- **GIVEN** Two angle bearings in degrees
- **WHEN** angleDifference is called
- **THEN** The shortest angular difference between 0.0 and 180.0 is returned

### Requirement: InCone

The system SHALL determine whether a target coordinate point lies within the angular arc and maximum range radius of a vision cone.

#### Scenario: TargetMatchesConeOrigin
- **GIVEN** A target point identical to the cone origin
- **WHEN** inCone is evaluated
- **THEN** Returns true regardless of facing direction or vision arc

#### Scenario: TargetOutsideMaximumRadius
- **GIVEN** A target point whose Euclidean distance exceeds the cone's MaxRadius
- **WHEN** inCone is evaluated
- **THEN** Returns false

#### Scenario: OmnidirectionalAwarenessWithinRange
- **GIVEN** A cone with Facing set to None and a target within MaxRadius
- **WHEN** inCone is evaluated
- **THEN** Returns true

#### Scenario: TargetWithinDirectionalVisionArc
- **GIVEN** A directional cone and a target within MaxRadius and within half the arc angle of the facing
direction
- **WHEN** inCone is evaluated
- **THEN** Returns true

#### Scenario: TargetOutsideDirectionalVisionArc
- **GIVEN** A directional cone and a target within MaxRadius but outside the angular arc
- **WHEN** inCone is evaluated
- **THEN** Returns false
