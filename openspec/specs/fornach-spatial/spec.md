# Fornach-spatial Specification

> Generated by openlore v1.2.0 on 2026-11-13 21:11

## Purpose

Calculates breadth-first distance maps radiating from goal points and determines gradient paths
toward or away from goals.

## Requirements

> `src/Fornach.Spatial/Dijkstra.fs`

### Requirement: Compute

The system SHALL the service shall compute a distance map from one or more goal points radiating outward across passable tiles up to maxdistance.

#### Scenario: SuccessfulDistanceMapGeneration
<!-- openlore-test: tags=smoke (auto) -->
- **GIVEN** A set of passable goal points and a valid maxDistance boundary
- **WHEN** compute is called
- **THEN** It MUST return a Map mapping points to step distances radiating outward from the nearest goal up to
maxDistance

#### Scenario: ImpassableGoalPoints
- **GIVEN** A goal point that is not passable according to isPassable
- **WHEN** compute is called
- **THEN** The impassable goal point MUST NOT be enqueued or included as distance 0

### Requirement: NextStepTowards

The system SHALL the service shall determine the neighboring tile that moves strictly closer to the goal based on the lowest dijkstra distance.

#### Scenario: NeighborCloserToGoalExists
- **GIVEN** A Dijkstra map and a current position with at least one neighboring point having a distance lower
than current
- **WHEN** nextStepTowards is called
- **THEN** It MUST return Some point corresponding to the neighbor with the minimum distance

#### Scenario: NoNeighborCloserToGoal
- **GIVEN** A current position where no neighbor has a distance strictly less than current
- **WHEN** nextStepTowards is called
- **THEN** It MUST return None

### Requirement: NextStepAway

#### Scenario: NoNeighborFartherFromGoal

### Requirement: Manhattan

The system SHALL the service shall calculate 4-directional grid distance between two points as |x1 - x2| + |y1 - y2|.

#### Scenario: ComputeManhattanDistance
- **GIVEN** Point a at (0, 0) and Point b at (3, 4)
- **WHEN** manhattan is called
- **THEN** It MUST return 7

### Requirement: Chebyshev

- **GIVEN** Point a at (0, 0) and Point b at (3, 4)
- **WHEN** chebyshev is called
- **THEN** It MUST return 4

#### Scenario: ComputeEuclideanDistance

- **WHEN** euclidean is called
- **THEN** It MUST return 5.0

- **THEN** It SHALL return None immediately without searching

The system SHALL the system shall calculate the minimal angular separation in degrees between two angles within the range [0.0, 180.0].

- **GIVEN** Two angles spanning across 0 and 360 degrees (e.g., 10 and 350 degrees)
- **WHEN** angleDifference is invoked

### Requirement: InCone

The system SHALL the system shall determine whether a target point falls within the angular aperture arc and maximum radius limit of an actor's vision cone.

#### Scenario: TargetIsTheConeOrigin
- **GIVEN** A target point identical to the cone's origin
- **WHEN** inCone is invoked
- **THEN** It SHALL return true regardless of facing direction or radius

#### Scenario: TargetExceedsMaximumRadius
- **GIVEN** A target point located farther than MaxRadius from the cone origin
- **WHEN** inCone is invoked
- **THEN** It SHALL return false

#### Scenario: OmnidirectionalAwareness
- **GIVEN** A vision cone with Facing set to None and target within MaxRadius
- **WHEN** inCone is invoked
- **THEN** It SHALL return true for any target within the maximum radius

#### Scenario: TargetWithinDirectionalFieldOfView
- **GIVEN** A directional vision cone with facing specified and target within both ArcDegrees/2 and MaxRadius
- **WHEN** inCone is invoked
- **THEN** It SHALL return true

#### Scenario: TargetOutsideDirectionalArc
- **GIVEN** A target within MaxRadius but positioned at an angle exceeding half of ArcDegrees from the facing
vector
- **WHEN** inCone is invoked
- **THEN** It SHALL return false
