# Fornach-spatial Specification

> Generated by openlore v1.2.0 on 2026-10-19 15:43

## Purpose

Computes flood-fill distance maps radiating from target goals and provides gradient-based
pathfinding to step towards or flee away from targets.

## Requirements

> `src/Fornach.Spatial/Dijkstra.fs`

### Requirement: Compute

The system SHALL the system shall compute a breadth-first step-distance map from one or more passable goal points up to a maximum distance.

#### Scenario: ValidGoalFloodFill
<!-- openlore-test: tags=smoke (auto) -->
- **GIVEN** A passable grid and a list of passable goal coordinates
- **WHEN** compute is invoked with a maximum distance threshold
- **THEN** A distance map SHALL be returned with goal tiles at distance 0 and passable neighbor tiles
incremented by 1 up to maxDistance

#### Scenario: ImpassableGoalCoordinate
- **GIVEN** A goal coordinate where isPassable evaluates to false
- **WHEN** compute is invoked
- **THEN** The impassable goal SHALL NOT be enqueued and SHALL NOT be included in the resulting distance map

### Requirement: NextStepTowards

The system SHALL the system shall determine the adjacent neighboring point that moves strictly closer to the nearest goal using an existing dijkstra distance map.

#### Scenario: NeighborCloserToGoalExists
- **GIVEN** A Dijkstra map where at least one neighbor has a lower distance than current
- **WHEN** nextStepTowards is evaluated for the current point
- **THEN** The neighbor with the lowest step distance SHALL be returned wrapped in Some

#### Scenario: NoNeighboringStepMovesCloser
- **GIVEN** A current position with no mapped neighbors or where no neighbor has a lower distance than current
- **WHEN** nextStepTowards is evaluated
- **THEN** None SHALL be returned

### Requirement: NextStepAway

The system SHALL the system shall determine the adjacent neighboring point that flees strictly further away from the nearest goal using an existing dijkstra distance map.

#### Scenario: NeighborFurtherFromGoalExists
- **GIVEN** A Dijkstra map where at least one neighbor has a greater distance than current
- **WHEN** nextStepAway is evaluated for the current point
- **THEN** The neighbor with the highest step distance SHALL be returned wrapped in Some

#### Scenario: NoNeighborMovesFurtherAway
- **GIVEN** A current position where all valid neighbors have distances less than or equal to current
- **WHEN** nextStepAway is evaluated
- **THEN** None SHALL be returned

The system SHALL compute the set of all visible grid points from a vision cone, taking into account obstacle occlusion and the cone's directional aperture and radius.

#### Scenario: ComputeVisiblePointsWithinCone

- **THEN** A set of all visible points within the cone bounds unobstructed by opaque obstacles, including the
origin point, SHALL be returned
