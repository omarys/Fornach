### Requirement: SingleCombatResultValidation

The system SHALL validate SingleCombatResult according to these rules:
- Rounds must be greater than or equal to 1
- TotalWhiffs and TotalCrits must be non-negative integers
- When Condition is Stalemate, WinnerName, WinnerId, WinnerIsA, and LoserName must be None
- When Condition is not Stalemate, WinnerName, WinnerId, WinnerIsA, and LoserName must have values

#### Scenario: RecordDecisive1v1CombatOutcome
- **GIVEN** A combat duel between combatant A and combatant B resolves via health depletion
- **WHEN** The match concludes
- **THEN** SingleCombatResult is recorded with WinnerIsA set, WinnerName populated, and Condition set to
HealthDepleted

#### Scenario: RecordStalemate1v1CombatOutcome
- **GIVEN** A combat duel reaches max allowed rounds without either combatant falling
- **WHEN** The match concludes
- **THEN** SingleCombatResult is recorded with WinnerIsA as None and Condition set to Stalemate

### Requirement: SimulationSummaryValidation

The system SHALL validate SimulationSummary according to these rules:
- TotalIterations must equal WinsA + WinsB + Stalemates
- TotalIterations must equal HealthDepletions + MoraleDepletions + Executions + Stalemates
- MinRounds must be less than or equal to MaxRounds
- AvgRounds must be between MinRounds and MaxRounds

#### Scenario: SummarizeBatchSimulation
- **GIVEN** A batch of N iterations of 1v1 combat between Archetype A and Archetype B has completed
- **WHEN** Aggregation is calculated
- **THEN** SimulationSummary contains exact counts of wins, stalemates, win conditions, and round metrics

### Requirement: GroupSingleResultValidation

The system SHALL validate GroupSingleResult according to these rules:
- OpponentsEliminated must be between 0 and OpponentsInitial inclusive
- SoloRemainingHPPct must be between 0.0 and 100.0 (or 0.0 and 1.0 depending on scale)
- SoloRemainingMoralePct must be between 0.0 and 100.0 (or 0.0 and 1.0 depending on scale)
- Rounds, OpponentsInitial, SoloExhaustion, SoloOverwhelm, and PeakEncirclementPenalty must be non-negative

#### Scenario: SoloDefeatsMob
- **GIVEN** A solo combatant facing an opposing mob
- **WHEN** All opponents in the mob are eliminated
- **THEN** GroupSingleResult is recorded with SoloWon = true and OpponentsEliminated equal to OpponentsInitial

#### Scenario: MobOverwhelmsSolo
- **GIVEN** A solo combatant facing an opposing mob
- **WHEN** The solo combatant's health or morale is depleted
- **THEN** GroupSingleResult is recorded with SoloWon = false and condition reflects the depletion

### Requirement: GroupSimulationSummaryValidation

The system SHALL validate GroupSimulationSummary according to these rules:
- TotalIterations must equal SoloWins + MobWins + Stalemates

### Introduction of CollapseDecisive Win Condition

**Status:** Approved
**Date:** 2026-10-28
