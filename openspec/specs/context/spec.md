## Requirements

### Requirement: ArchetypeInfoValidation

The system SHALL validate ArchetypeInfo according to these rules:
- Name must be non-empty
- Factory must yield a valid Combatant instance corresponding to the designated Tier and Discipline

#### Scenario: InstantiateCombatantFromArchetype
- **GIVEN** A configured ArchetypeInfo instance
- **WHEN** The Factory function is invoked
- **THEN** A new Combatant initialized according to the archetype profile is returned

### Requirement: SingleCombatResultValidation

The system SHALL validate SingleCombatResult according to these rules:
- Rounds must be non-negative
- TotalWhiffs and TotalCrits must be non-negative
- If Condition is Stalemate, WinnerName and WinnerId must be None

#### Scenario: RecordDecisiveCombatOutcome
- **GIVEN** Two combatants engage in a duel
- **WHEN** One combatant's health is depleted
- **THEN** A SingleCombatResult is generated with Condition set to HealthDepleted and the surviving combatant
marked as the winner

### Requirement: SimulationSummaryValidation

The system SHALL validate SimulationSummary according to these rules:
- TotalIterations must equal WinsA + WinsB + Stalemates
- TotalIterations must equal HealthDepletions + MoraleDepletions + Executions + Stalemates
- MinRounds must be less than or equal to MaxRounds

#### Scenario: SummarizeBatch1v1DuelIterations
- **GIVEN** A completed batch of N duel iterations between archetype A and B
- **WHEN** Results are compiled
- **THEN** A SimulationSummary is produced where the sum of win counts and stalemates matches the total
iterations

### Requirement: GroupSingleResultValidation

The system SHALL validate GroupSingleResult according to these rules:
- OpponentsEliminated must be between 0 and OpponentsInitial
- SoloRemainingHPPct and SoloRemainingMoralePct must be within 0.0 to 100.0
- Rounds, OpponentsInitial, and OpponentsEliminated must be non-negative

#### Scenario: SoloCombatantSurvivesMob
- **GIVEN** A solo combatant facing an initial mob of N opponents
- **WHEN** All N opponents are eliminated before the solo combatant falls
- **THEN** SoloWon is true, OpponentsEliminated equals OpponentsInitial, and remaining HP/morale percentages
are recorded

### Requirement: GroupSimulationSummaryValidation

The system SHALL validate GroupSimulationSummary according to these rules:
- TotalIterations must equal SoloWins + MobWins + Stalemates
- SoloWinRate must be between 0.0 and 1.0 (or 0.0 and 100.0 depending on scaling convention)
- MobCount must be greater than 0

#### Scenario: ComputeSoloWinRateAcrossGroupIterations
- **GIVEN** A simulated batch of solo vs. mob battles
- **WHEN** Simulation results are aggregated into GroupSimulationSummary
- **THEN** SoloWinRate equals SoloWins divided by TotalIterations and elimination distribution buckets are
populated

### Requirement: TowerFloorValidation

The system SHALL validate TowerFloor according to these rules:
- Movement is permitted only to coordinates with walkable tiles that are not blocked by active entities
- Pillars and out-of-bounds tiles block line of sight, whereas floors, chasms, archways, hazards, and portals are transparent

#### Scenario: ValidateMovementToUnblockedWalkableTile
- **GIVEN** A TowerFloor with a walkable Floor tile and no blocking entity at a target Point
- **WHEN** CanMoveTo is evaluated for that Point
- **THEN** Returns true allowing movement

#### Scenario: BlockMovementIntoAnEntityOrObstruction
- **GIVEN** A TowerFloor with an entity that blocks movement or a non-walkable Pillar at target Point
- **WHEN** CanMoveTo is evaluated for that Point
- **THEN** Returns false preventing movement

#### Scenario: UnlockFloorAscensionStairway
- **GIVEN** A TowerFloor where StairwayLocation contains a StairwayPortal
- **WHEN** UnlockStairway() is executed
- **THEN** The tile at StairwayLocation updates to StairwayPortal DoorState.Open and IsStairwayOpen returns
true

### Requirement: TowerQuestValidation
