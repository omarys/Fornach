# ADR-0008: Every defensive action pays the guard meters that harden the hold

## Status

accepted (auto-accepted, unreviewed)

**Domains**:

## Context

Fortitude and Resolve scale off the Inertia/Focus guard ramps (2.5 percent per stack), so a defensive move hardens the hold exactly when it pays guard stacks. (Poise/Composure no longer ramp at all -- discipline is earned through stressed growth, per the stress-gated growth decision.) The four active defences already did; the recoveries SteadyForm and CenterMind still fed the Flow/Momentum offense ramp, so acting defensively sharpened offence instead of the guard.

## Decision

Every defensive action pays the guard meters that harden Fortitude/Resolve

## Consequences

Recovery actions SteadyForm, RaiseShield and CenterMind now grant Inertia/Focus guard stacks instead of Flow/Momentum; Prowess/Acumen/Poise/Composure never ramp in combat -- they are earned only through stressed growth
